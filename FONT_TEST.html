✨ ทดสอบฟอนต์ภาษาไทย

⭐ 1. Kanit (ฟอนต์หลัก - ใช้งานจริง)

ฟอนต์ Kanit สวย หรู ดูแพง เหมาะกับเว็บความงาม

✓ ใช้งานจริงในเว็บ - ฟอนต์นี้สวยที่สุด!

ความหมาย: "นคร" หรือเมือง สื่อถึงความทันสมัยและหรูหรา

2. Prompt (ฟอนต์สำรอง #1)

ฟอนต์ Prompt เป็นฟอนต์ภาษาไทยสไตล์ทันสมัย

ใช้เป็นตัวเลือกที่สองหาก Kanit ไม่โหลด

3. Sarabun (ฟอนต์สำรอง #2)

ฟอนต์ Sarabun เป็นฟอนต์ภาษาไทยที่อ่านง่าย

ใช้เป็นตัวเลือกที่สามหาก Kanit และ Prompt ไม่โหลด

4. System Fonts (ฟอนต์สำรองสุดท้าย)

หาก Google Fonts ไม่โหลด จะใช้ฟอนต์ของระบบ

บน Windows: Tahoma, Leelawadee

บน Mac: Thonburi, Ayutthaya

ข้อความทดสอบพิเศษ

วิธีตรวจสอบ

  1. ถ้าอ่านภาษาไทยได้ทุกบรรทัด = ฟอนต์ทำงานปกติ ✓
  2. ถ้าเห็นสี่เหลี่ยมสีขาวหรือตัวแปลกๆ = ฟอนต์ไม่โหลด ✗
  3. กด F12 → Console ดูว่ามี error เรื่อง font หรือไม่
