# Aura Medical Aesthetics Website

เว็บไซต์สำหรับคลินิกความงาม Aura Medical Aesthetics - เว็บไซต์สมบูรณ์แบบพร้อมใช้งาน

## 🌟 Features

### Core Features
- **Hero Animation**: ข้อความปรากฏทีละคำพร้อม animation effect
- **Before/After Slider**: ส่วนเปรียบเทียบผลลัพธ์ก่อนและหลังการรักษา (ใช้รูปจริง!)
- **Treatment Cards**: การ์ดบริการ 6 บริการ พร้อม hover effects
- **Trust Signals**: ดาวรีวิวที่ปรากฏเมื่อ scroll มาถึง
- **Multi-step Booking Form**: ฟอร์มจองคิวแบบ 3 ขั้นตอนพร้อม progress bar
- **FAQ Accordion**: คำถามที่พบบ่อยแบบ interactive

### Additional Sections
- **Navigation Bar**: Sticky navigation พร้อม mobile responsive menu
- **About Section**: แนะนำคลินิกพร้อมสถิติ
- **Pricing Section**: แพ็กเกจราคา 3 ระดับ
- **Gallery**: ผลงาน 6 รายการ
- **Testimonials**: รีวิวจากลูกค้า 3 รายการ
- **Contact Section**: ข้อมูลติดต่อพร้อมแผนที่
- **Footer**: Footer พร้อมข้อมูลและ social links

## 🛠 Technologies

- **HTML5** - Semantic markup
- **CSS3** - Custom Properties, Animations, Flexbox & Grid
- **Vanilla JavaScript** - No frameworks, pure JS
- **Font Awesome 6.5** - Icons
- **Google Fonts**:
  - Kanit (ฟอนต์หลัก - ภาษาไทย)
  - Prompt (ฟอนต์สำรอง)
  - Playfair Display (ฟอนต์หัวข้อ)

## 🎯 Sections Breakdown

1. **Hero Section** - ข้อความต้อนรับพร้อม animation + รูปภาพ
2. **About Section** - แนะนำคลินิกพร้อมสถิติ (10,000+ ลูกค้า)
3. **Before/After** - ส่วนเปรียบเทียบผลลัพธ์ (ใช้รูปจริง!)
4. **Services** - 6 บริการ (Botox, Filler, Laser, HIFU, Thread Lift, Skin Booster)
5. **Trust Section** - แพทย์ผู้เชี่ยวชาญ + ดาวรีวิว
6. **Testimonials** - รีวิวจากลูกค้า 3 ราย
7. **Pricing** - แพ็กเกจ 3 ระดับ (Basic, Popular, Premium)
8. **Gallery** - ผลงาน 6 รายการ
9. **FAQ** - คำถามที่พบบ่อย 5 ข้อ
10. **Contact** - ข้อมูลติดต่อ + แผนที่
11. **Booking** - ฟอร์มจองคิว 3 ขั้นตอน
12. **Footer** - ข้อมูลเพิ่มเติม
